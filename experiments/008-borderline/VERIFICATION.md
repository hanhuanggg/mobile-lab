# MVP 验证记录

日期：2026-11-08。环境：Node 24、Chromium、Linux。验证针对 TypeScript 源码与生成的静态网页，未使用后端或外部素材服务。

## 已执行

- `npm install`：成功。
- `npm test`：**21 项通过**。覆盖初始状态、费用恢复、非法部署、占用与数量上限、返费与冷却、先锋补给、暂停/倍速、物理与法术计算、四向范围、有限阻挡、撤退/阵亡释放、医疗优先级与收割者排除、解放者、收割者、术师、重装、领主、狙击、医疗技能，以及完整关卡的胜败。
- `npm run test:e2e`：**7 项通过**。真实 Chromium 和 Phaser Canvas/WebGL 下验证首页、手册、音效持久化、记录、部署与方向确认、非法格不扣费、撤退、倍速、暂停、重开、胜败结算、再次挑战、320px/390px 竖屏、844×390 横屏与触控。

- 生产静态版本：从陈列馆点击进入游戏，加载真实场景，暂停并使用 UI 部署一名干员成功。确认 `window.__borderline` 开发测试入口不存在。

- `git diff --check`：通过。

## 关卡结果

测试从 10 DP 开始，按正常费用依次部署 README 中的 8 名干员，没有修改费用、生命或伤害。技能按实际冷却释放。完整战斗模拟结果：**约 183 秒通关，歼灭 37/37，剩余 3/3 生命**。不部署时，敌人抵达终点并正常触发失败。

关卡验证使用实际模拟的时间步加速执行，未等待完整 3 分钟现实时间。浏览器端同时检查真实部署交互、渲染、结算、记录与重置；纯战斗规则另由无渲染测试覆盖。
