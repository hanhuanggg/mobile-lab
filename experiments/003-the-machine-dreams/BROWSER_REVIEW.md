# 观影入口验证

在 Chromium 中通过本地 HTTP 实际验证，视口为 320×844、390×844、1366×1000。

- 三种宽度下首页均显示 4 件作品，可点击 003 进入独立观影页；首页和观影页没有横向溢出。
- 视频元数据实际读取为 1920×1080、15 秒。默认暂停，不自动播放；在减少动态效果偏好下仍由用户主动开始。
- 原生播放、暂停、跳至中途、从头重播、结束后重播均已验证。390px 视口实际连续播放完整 15 秒至结束；另两种视口通过跳至片尾验证结束状态。
- 重播按钮键盘焦点可达、目标高度 46px；状态通过 `role="status"` 播报。快速暂停导致的正常 `AbortError` 不显示为播放失败。
- 下载链接响应为 200，文件长度 36,979,103 字节；制作笔记和返回陈列馆链接均通过。
- 三种宽度没有页面脚本错误或 HTTP 资源错误，并检查了手机与桌面的实际截图。
- 所有 33 个 HyperFrames 项目文件与原始交付逐字节一致，MP4 的 SHA-256 与输出 manifest 一致；本次只增加观影入口和仓库索引，没有修改成片。

普通 Python `http.server` 的 HTTP Range 限制在测试中复现，因此补充 `serve.py`。在该服务器上复核所有播放交互，另外验证 `bytes=0-15` 和后缀范围返回正确的 206 与文件内容，超出文件范围返回 416。

没有发布或验证线上托管站点；没有声称验证过实体手机、Safari 或移动设备的系统全屏。原片的逐帧审查与声音测量见 `hyperframes/REVIEW.md`。
