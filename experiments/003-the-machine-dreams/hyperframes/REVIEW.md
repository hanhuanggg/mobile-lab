# 自我审查

## 修订

- 第一版的完整片名太平，容易读成一张标题页。加入从同一晶格翻卷出来的实体曲面，使它与文字发生前后遮挡；提高文字深度形变。
- 第一版细线密度和亮度过于平均。减少层流丝数量，降低次要网格亮度，让主轮廓、曲面高光和文字分出层级。
- 第二版曲面长期遮挡片名中部。增加 9.15–10.65 秒的侧向剥离，使完整字形在运动中露出；保留局部遮挡，避免标题页构图。

## 八项检查

| 问题 | 审查结果 |
| --- | --- |
| PPT 感 | 全片同一投影空间；没有切换画面或页面章节。片名受到真实几何遮挡、形变和镜头穿越 |
| 连续 1 秒几乎不动 | 开头有持续纵深推进；异常后运动逐渐增强。只有最后识别阶段有意减速，落点后的短停顿约 0.27 秒 |
| 依赖淡入淡出 | 主转换由几何 morph、裁切、节点重组、曲面翻卷与镜头推进完成；没有全画面交叉淡化 |
| 独立网页 section | 只有一个 Canvas 世界和一个根 GSAP timeline |
| 视觉因果 | 单元偏移 → 网格响应 → 晶格形成曲面和字形 → 文字成为可穿越的结构 → 时间刹车与凝视 |
| 空间感 | 前后绘制、透视缩放、遮挡、深度相位差、镜头横向弧线与纵向加速 |
| 15 秒内演化 | 正交空间变成柔性拓扑结构，文字从小节点长成建筑尺度，最后回到微小孔径 |
| 值得暂停的瞬间 | 约 12.3–12.6 秒：字形成为覆盖画幅的弯曲条带，镜头从内部通过 |

## 实际验证

- HyperFrames 0.8.198 完整 `check` 通过。浏览器实际运行，9 个常规采样、120 个 craft 时间采样；没有 runtime、layout、motion/craft 错误。
- 保留一条 `composition_file_too_large` 警告：单镜头的生成代码被嵌入 `index.html` 供静态检查，编辑用源码已拆到 `src/`。没有为了消除该警告而拆成多个画面。
- Canvas 内文字不具备 DOM 字框，HyperFrames 的文字对比度审计没有检查到字形；以实际关键帧作视觉检查，没有将 `checked=0` 说成对比度通过。
- 11 个时间点分别正序与倒序 seek，像素哈希完全一致，无页面脚本错误。见 `preview/seek-verification.json`。
- 最终 MP4 全部 450 帧解码成功，H.264 / yuv420p / 1920×1080 / 30fps / 15.000 秒。FFmpeg 完整解码无错误。
- 最终成片逐帧生成 9 张 50 帧审查图，全部视觉检查；逐帧计算差异与哈希。只有最终黑场的 448、449 帧与上一帧完全相同。详见 `preview/frame-analysis.json`，本地审查图位于 `preview/all-frames/`。
- 声音为 AAC 立体声，音量测量见 `preview/audio-analysis.txt`。音轨已测量，没有用听感审片；没有音乐、旁白或采样素材。
- 独立的静帧审查没有发现阻止交付的 P0/P1 项；连续性判断来自导出后全部帧检查，而非只看关键帧。

## 创作取舍与边界

选择冷静、低亮度的计算空间，放弃拟人角色、完整故事和 glitch 爆炸。最弱的部分是 3–4.5 秒的异常非常克制，小屏幕上需要专注才能注意到数据单元的偏移；这是“异常开始时系统尚未承认它”的节奏选择。继续迭代时可略加强邻近节点的相位响应，同时保留安静程度。

片名有意保留曲面穿插和局部遮挡。最完整的可读窗口在约 10.4–11.6 秒；它没有脱离空间成为标题卡。
