## 规则层验证

`node experiments/005-hanzi-changban/tests/core.mjs` 通过15项检查：六张地图连通与边界、非法布阵、资金不足、移动合成、升级上限、经济退款、障碍补给、暂停、技能冷却、名将字牌消耗与救主效果、失败后禁止改写，以及六关用战斗所得资源通关。

发现并修复一个数值问题：90×0.7在浮点运算中可能向下取整为62。撤回计算改为整数先乘7再除10，合成弓兵正确返还63军粮。

## 复现

```sh
python3 -m http.server 8000 --bind 0.0.0.0
node --check experiments/005-hanzi-changban/main.js
node --check experiments/005-hanzi-changban/core.js
node experiments/005-hanzi-changban/tests/core.mjs
# 另一个终端；测试环境需有 Playwright Python 和 Chromium。
python experiments/005-hanzi-changban/tests/browser.py
```

浏览器测试默认将截图与JSON报告写到 `/tmp/changban-review/`，可以用 `CHANGBAN_REPORT_DIR` 修改；服务器地址可用 `CHANGBAN_BASE_URL` 修改。测试工具仅用于开发，不参与作品运行。
