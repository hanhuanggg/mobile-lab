业务测试覆盖：

- 首次初始化与幂等性，删除所有计划后不会重新初始化示例。
- IndexedDB 中每组数据的持久化，并通过新的数据库连接验证恢复。
- 连续快速修改的写入顺序，已放弃训练不会被迟到写入重建。
- 同时发起两次训练，数据库中只存在同一个 active session。
- 仅统计完成组，结束时保存历史快照，修改计划 / 动作名称不改变历史。
- 完成后按训练日轮换；同一动作跨计划继承最近实际重量与次数。
- 阻止零完成组被保存成历史记录。
- 全量备份与原子恢复，包含未完成训练；训练中拒绝覆盖导入。
- 历史删除后的持久化。
- JSON 版本、类型、重复 ID、数字范围、引用、快照校验，错误文件不改动数据。
- 不支持 `crypto.randomUUID` 的局域网 HTTP 预览环境仍可生成稳定 UUID。

## 浏览器完整流程

测试对象是仓库静态服务器提供的**真实生产构建**，使用浏览器原生 IndexedDB；各场景采用独立 browser context，未注入展示历史或虚假保存结果。

1. 首次打开 → 三份示例计划 → 开始 → 逐键输入 `62.5` kg → 修改次数 → 勾选完成 → 跳过休息 → 添加 / 删除一组 → 刷新恢复 → 保存并结束 → 查看总结 → 返回首页 → 自动选中下一计划 → 查看历史 → 再次训练继承历史数据。实际完成 `62.5 × 8 + 60 × 7 = 920 kg`，未完成的 `999 kg` 组未计入，历史仅保存 2 组。
2. 修改训练 → 关闭页面 → 同一浏览器上下文新建页面 → 恢复 `42.5 kg` → 验证三个退出选项 → 继续 → 二次确认放弃 → 等待事务结束 → 刷新确认已清除。
3. 创建计划 → 搜索动作 → 调整目标 → 创建自定义动作 → 上移顺序 → 保存 → 刷新 → 再编辑名称和目标 → 二次确认删除。
4. 真实训练后下载 JSON → 删除记录时取消确认 / 确认删除 → 拒绝错误 JSON → 显示备份与覆盖提示 → 导入原 JSON → 刷新确认记录恢复。
5. 320 / 360 / 390 / 430 / 1440 px 视口无横向溢出；首页所有可见按钮宽高至少 44 px。360 px 训练输入表格无横向溢出。等待 Service Worker 激活后断网 → 刷新 → 恢复 `22.5 kg` → 离线完成并保存训练，容量为 `22.5 × 8 = 180 kg`。
6. 设置休息为 60 秒 → 尝试保存零完成组 → 错误提示在当前 dialog 内可见 → 继续训练 → 完成一组显示 `01:00` → 选择放弃后取消 → 已完成状态仍然保留。

所有六条用例均断言没有 `pageerror` 或 `console.error`。实际抓取手机首页、训练中、训练总结和桌面首页截图并进行视觉复查。
