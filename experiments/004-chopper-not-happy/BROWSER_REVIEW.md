# 观影入口验证

通过本地支持 HTTP Range 的服务器，在 Chromium 视口 320×844、390×844、1366×1000 实际验证。

- 首页陈列为 5 件，点击实验 004 可到达独立观影页，返回链接正确。
- 首页与实验页没有横向溢出；重播按钮高度至少 44px，键盘焦点可达。
- 初始暂停，不自动播放；设置减少动态效果偏好后仍由用户主动开始。
- 视频实际元数据为 1920×1080、15 秒，能播放、暂停、拖到中途、从头重播、结束后重播。
- 390px 视口实际连续播放完整 15 秒至结束，另外两个视口通过跳到片尾验证结束状态。
- 下载链接响应 200，长度 17,729,772 字节；制作笔记和返回陈列馆链接均响应正常。
- 没有页面脚本错误或 HTTP 资源错误；检查了实际手机和桌面截图。

没有发布线上托管站点，没有声称测试过实体手机、Safari 或系统全屏。影片逐帧与声音测量见 `hyperframes/REVIEW.md`。
