## 教师使用

使用 PowerPoint 桌面版打开 PPTX，在“备注”或“演讲者视图”中查看逐页教学提示、问题、活动词表及科学表述补充。页面以学生投影阅读为目标，详细解释保留在备注区。

字体使用免费的 **Noto Sans CJK SC（思源黑体同源字体）**。如果电脑未安装，建议先安装 [Noto Sans CJK](https://github.com/notofonts/noto-cjk)，或在 PowerPoint“替换字体”中换成微软雅黑。PDF与PNG预览使用实际渲染结果，便于快速核对。

课前准备：黑板或白板、4名作画同学、纸笔、计时器；第20页计划模板可独立打印。游戏不评价绘画能力或记忆能力，学生可在座位做简笔记录。

## 科学表述

- 三车间是经典信息加工模型的教学隐喻，不是大脑的物理解剖分区。
- 感觉记忆时长随通道而变；教案中的0.25–2秒是便于理解的近似范围，听觉痕迹可能持续更久。
- 短时记忆的1秒–1分钟不是固定定律；未复述的信息常在数十秒内衰退。
- 7±2是经典估计，不是每个人固定拥有7个格子。现代工作记忆研究在一些条件下常估计约4组块。
- 长时记忆不代表永不遗忘或回忆绝对准确；提取失败也不等于痕迹已彻底消失。
- 遗忘曲线的数据为**教学示意**，并非艾宾浩斯原始实验数据或个人预测。时间轴不按真实时间比例。当天、第2天、第7天是示例安排，需按掌握情况调整。
- 情绪可影响注意、编码和巩固；更鲜明不保证更准确，过强压力可能妨碍回忆。杏仁核为简化投影位置示意。
- “能讲明白，才是真的会”是学习提醒；表达困难还可能来自紧张、语言或提取困难，不据此给学生贴能力标签。

## 编辑与重建

PPTX中的正文、标题、卡片、工作台、流程、路径、箭头及曲线图均为原生PowerPoint元素。图标、大脑和学生为独立SVG，可以替换或在新版PowerPoint中转换成形状。没有整页PNG幻灯片。所有SVG均保留矢量版本，并生成了真实PNG兼容预览。小型图标来自Lucide，许可见 [LUCIDE-LICENSE.txt](assets/LUCIDE-LICENSE.txt)。大脑与学生SVG由本项目绘制，视觉参考图没有复制进仓库。

```sh
cd experiments/006-memory-factory
npm ci
npm run build
```

代码见 `src/build.cjs`。`src/layout-audit.json` 是构建时记录的文本边界信息。生成PPTX后使用LibreOffice导出PDF，再运行 `python3 src/render.py` 生成22页PNG预览及4张检查总览。Python脚本需要PyMuPDF与Pillow。运行 `python3 src/verify.py` 验证页面数量、宽高比、元素边界、备注、时长、原生图表和预览数量。

本次已实际用LibreOffice渲染全部22页并人工检查，详情见 [verification.json](verification.json)。未在Microsoft PowerPoint桌面程序中执行兼容性测试。未预设复杂动画；第8、9、10、12及21页保持统一阶段编号、颜色与图示，方便教师自行添加“平滑”切换。
